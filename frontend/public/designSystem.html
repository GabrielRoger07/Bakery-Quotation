Design System

Uma referência visual completa de tokens, componentes, estados e padrões de layout — extraída diretamente do frontend de produção.

Outfit · JetBrains Mono Purple / Indigo 160ms transitions lucide-react Tailwind CSS v4
Sobre este sistema. Bakery Quotation é uma plataforma B2B de compras onde empresas publicam cotações e convidam fornecedores para dar lances — suportando modo de leilão em tempo real e modo de proposta única. A linguagem visual é limpa, profissional e autoritária, ancorada em uma identidade de marca em roxo escuro.

05

Animações & Transições

Todos os elementos interativos usam 160ms ease para micro-transições. Animações de nível de página são mais longas e expressivas.

authIn · 0.3s ease-out
modalIn · 0.2s cubic-bezier(0.16,1,0.3,1)
supplierAppear · 0.25s ease-out
spin · 0.65s linear infinite
Padrão de transição: todos os elementos interativos usam transition: [props] 160ms ease. Botões incluem transform e box-shadow na lista de transição para o efeito de elevação no hover.
